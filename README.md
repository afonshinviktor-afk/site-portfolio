Сайт-портфолио

Одностраничный сайт-портфолио в неоновом стиле. Весь сайт лежит в одном файле portfolio.html: без сборки, без зависимостей, без серверной части.

Что на сайте
Шапка: закрепленное меню со ссылками на разделы, ФИО, инициалы на аватарке и учебное заведение.
Достижения: грамоты и медали в виде цветных карточек.
Образовательное учреждение: карточка с названием школы.
Питомцы: карточка с питомцем.
Контакты: кликабельная плитка с телефоном.
Как открыть
Скачайте portfolio.html.
Дважды щелкните по файлу, он откроется в браузере.

Интернет нужен только для шрифта Montserrat. Без подключения к сети страница работает, но шрифт будет системным.

Как изменить содержимое

Откройте portfolio.html в Блокноте или редакторе кода (например, VS Code) и внесите изменения в текст между тегами в части <body>. Сохраните файл в кодировке UTF-8.

Добавить достижение

Скопируйте блок карточки внутри <section id="achievements"> и измените текст:

html
<div class="card">
  <h3>Название награды</h3>
  <p class="meta">Где и за что получена</p>
</div>

Цвета первых трех карточек задаются в CSS строками #achievements .card:nth-child(...). Для четвёртой и последующих строк добавьте такую же строку с нужным номером.

Добавить контакт

Внутри <section id="contacts"> добавьте плитку:

html
<a class="card contact" href="https://t.me/ваш_ник"><small>Telegram</small>@ваш_ник</a>

Для почты используйте href="mailto:адрес@example.com", для телефона href="tel:+7XXXXXXXXXX".

Добавить раздел
Скопируйте любой блок <section id="..."> и дайте ему новое id.
Добавьте пункт в меню: <li><a href="#новый-id">Название</a></li>.
Изменить цвета

Цвета находятся в начале <style>, в блоке :root:

css
--purple:#8847ff;  --pink:#d32ce6;  --blue:#4b69ff;
--gold:#e4ae39;    --red:#eb4b4b;

Фон и панели меняются с помощью переменных --bg и --panel.

Как выложить в интернет (GitHub Pages)
Создайте репозиторий на GitHub.
Переименуйте файл в index.html и загрузите его в репозиторий.
Откройте «Настройки» → «Страницы» и выберите ветку main и папку / (root).
Через минуту сайт появится по адресу https://ваш-логин.github.io/название-репозитория/.
Особенности
Адаптивная вёрстка: работает на телефоне и компьютере.
Плавная прокрутка к разделам по клику в меню.
Фоновое свечение с медленной анимацией. Если в системе включено уменьшение движения, анимация отключается.
Важно

Телефон на сайте виден всем, у кого есть ссылка или файл. Если вы не хотите публиковать личные данные, удалите плитку контактов или замените ее на другой способ связи.
